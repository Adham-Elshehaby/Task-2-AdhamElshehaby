# Project 2: Data Classification Using AI

## What it does
This project is applying an already existing classification algorithm to an already existing dataset. In other words, this project is made to just put them together in order to see how the classification algorithm works and how it handles all cases.

## How it runs
To run this model, type: python "project 2" in the terminal. 

## How it works
First, the iris dataset loads, and the data is placed into a dataframe. Then the data contained in that dataset is split into training and testing sets. Next the K-Nearest Neighbors classification algorithm is applied to the testing set, it is then used to predict results. These results are printed to the terminal, then finally the accuracy score of the model is evaluated and also printed to the terminal.
